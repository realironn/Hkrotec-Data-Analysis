# 한국로텍 데이터 분석

Windows PC의 브라우저에서 Jupyter 노트북을 열어 검사 결과와 생산·도금 기록을 분석합니다. 준비된 서버에는 실제 회사 자료와 실행 결과가 연결되어 있습니다.

## 처음 이용하시는 분

1. 담당자에게 받은 접속용 링크 전체를 엽니다. 처음 ngrok 안내 화면이 나오면 **Visit Site**를 누릅니다.
2. 아래로 내려가며 표와 그래프를 확인합니다. 전체 요약은 노트북 첫 부분의 **분석 보고서 열기**를 누릅니다.
3. 다시 계산하려면 화면 맨 위에서 **Run(실행) → Run All Cells(모든 셀 실행)**를 누릅니다.
4. 약 3~5분 뒤 맨 아래에 **분석 완료**가 나오면 끝입니다.

공유 링크로 이용할 때는 Python·Docker 설치나 SSH 접속, 코드 수정이 필요하지 않습니다. 이미 계산된 표와 그래프는 접속 후 바로 볼 수 있습니다. 자세한 조작과 오류 대처는 [사용 안내](./docs/user-guide.md)를 참고합니다.

GitHub에서는 코드와 설명을 확인하고, 실제 데이터 분석은 별도로 받은 서버 링크에서 실행합니다. 접속 정보가 포함된 링크는 공개 저장소에 올리지 않습니다. 접속 후에는 왼쪽 `공유용_노트북_링크.txt`에서도 주소 전체를 복사할 수 있습니다.

## 서버 화면의 파일과 폴더

| 이름 | 용도 |
| --- | --- |
| `한국로텍_데이터분석.ipynb` | 표·그래프를 확인하고 전체 분석을 실행하는 노트북 |
| `분석결과` | 분석 보고서·계산표·그래프, 추가자료 반영 시 생성되는 모델 |
| `추가자료` | 새 자료를 작성할 양식과 업로드할 입력 폴더 |
| `raw` | 회사에서 받은 원본 Excel·PPT 자료 |
| `csv` | 원본을 분석에 사용할 수 있도록 변환한 자료 |
| `prepared` | 기존 집계·검증 기준과 비공개 분석참고자료 |
| `공유용_노트북_링크.txt` | 다른 이용자에게 전달할 접속 링크 |

원본·변환·검증자료는 열람하거나 내려받을 수 있습니다. 새 자료는 `추가자료/입력`에 정해진 양식으로 올립니다. 회사 자료와 실행 결과, 접속 정보는 서버에 별도로 보관합니다.

## 확인할 수 있는 내용

- 날짜별 검사수량과 불량기록
- 분석 대상 품목의 전류·전압·온도·처리시간
- 도금액 성분, 약품 사용량과 불량기록의 관계
- 월별 약품 사용량과 전력량
- 과거 자료로 계산한 예측과 실제 결과의 차이

검사자료에 품번과 생산묶음 번호(LOT)가 없어 날짜를 기준으로 비교합니다. 함께 변하는 경향이 있다고 해서 불량의 원인이 확인된 것은 아닙니다.

## 새 자료 추가하기

1. 왼쪽 `추가자료/양식`에서 CSV 또는 Excel 양식을 내려받습니다.
2. 전체 품목의 하루 집계를 한 행씩 작성해 `추가자료/입력`에 올립니다.
3. 노트북을 전체 실행하고 보고서의 추가자료 반영 결과를 확인합니다.

검사 결과가 있는 자료는 기존 자료와 함께 모델을 다시 학습하며, 검사 결과가 없는 자료는 예측만 계산합니다. 열 이름과 단위를 유지하고, 서로 다른 회사 원본 Excel은 담당자가 양식에 맞게 정리합니다. [입력 양식과 자세한 추가 방법](./docs/additional-data.md)
