# 한국로텍 데이터 분석

검사 결과와 생산·도금 기록을 모아 불량 현황과 작업조건의 관계를 살펴봅니다.

## 처음 이용하시는 분

담당자에게 받은 접속용 링크를 엽니다. 이 링크에는 접속 정보가 포함되어 있어 별도 로그인 코드 입력 없이 분석 화면이 열립니다.

1. 담당자에게 받은 접속용 링크를 그대로 엽니다. 주소 뒷부분을 생략하지 않습니다.
2. 아래로 내려가며 표와 그래프를 확인합니다. 전체 요약은 노트북 첫 부분의 분석 보고서 열기를 누릅니다.
3. 다시 계산하려면 화면 맨 위에서 Run(실행) → Run All Cells(모든 셀 실행)를 누릅니다.
4. 약 3~5분 뒤 맨 아래에 분석 완료가 나오면 끝입니다.

설치하거나 코드를 수정할 필요는 없습니다. 처음 접속할 때 ngrok 안내 화면이 나오면 Visit Site를 누릅니다.
화면 조작과 오류 대처는 [처음 이용하는 분을 위한 안내](./docs/user-guide.md)에 정리했습니다.

## 확인할 수 있는 내용

- 날짜별 검사수량과 불량기록
- 분석 대상 품목의 전류·전압·온도·처리시간
- 도금액 성분, 약품 사용량과 불량기록의 관계
- 월별 약품 사용량과 전력량
- 과거 자료로 계산한 예측과 실제 결과의 차이

검사자료에 품번과 생산묶음 번호(LOT)가 없어 날짜를 기준으로 비교합니다. 함께 변하는 경향이 있다고 해서 불량의 원인이 확인된 것은 아닙니다.

## 새 자료 추가하기

왼쪽 `추가자료/양식`의 CSV 또는 Excel 양식을 작성해 `추가자료/입력`에 올리고 전체 실행합니다. 검사 결과가 있는 자료는 기존 자료와 함께 모델을 다시 학습하며, 검사 결과가 없는 자료는 예측만 계산합니다. 전체 보고서에서 추가자료 반영 결과를 확인할 수 있습니다.

열 이름과 단위가 정해진 양식을 사용합니다. 서로 다른 회사 원본 Excel은 담당자가 양식에 맞게 정리한 뒤 넣습니다. [새 자료 추가 방법](./docs/additional-data.md)

GitHub에서는 노트북 내용을 볼 수 있습니다. 실제 계산은 담당자가 별도로 전달한 접속용 링크에서 실행합니다. 접속 정보가 들어 있는 링크는 이 공개 문서에 게시하지 않습니다.

회사 자료는 이 저장소에 포함하지 않습니다. 서버에는 담당자가 자료를 준비해 두었습니다. 내 PC에 직접 설치하는 경우에는 담당자에게 `raw`, `csv`, `prepared` 폴더와 `한국로텍_분석참고자료.json`을 별도로 받아야 합니다. 자세한 배치 방법은 Windows 설치 안내를 참고해 주세요.

Python 3.14 환경을 사용합니다. 2026-10-25에 실제 자료로 전체 실행과 검증 항목 15개를 확인했으며, 원본 파일은 변경되지 않았습니다.
