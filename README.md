# 한국로텍 데이터 분석

검사 결과와 생산·도금 기록을 모아 불량 현황과 작업조건의 관계를 살펴봅니다.

## 처음 이용하시는 분

**[분석 화면 열기](https://wobbling-unreeling-moisten.ngrok-free.dev/lab/tree/%ED%95%9C%EA%B5%AD%EB%A1%9C%ED%85%8D_%EB%8D%B0%EC%9D%B4%ED%84%B0%EB%B6%84%EC%84%9D.ipynb)**

1. 위 링크를 엽니다. 로그인 화면이 나오면 담당자에게 받은 로그인 코드를 입력합니다.
2. 아래로 내려가며 표와 그래프를 확인합니다. 전체 요약은 노트북 첫 부분의 **분석 보고서 열기**를 누릅니다.
3. 다시 계산하려면 화면 맨 위에서 **Run(실행) → Run All Cells(모든 셀 실행)**를 누릅니다.
4. 약 3~5분 뒤 맨 아래에 **분석 완료**가 나오면 끝입니다.

설치하거나 코드를 수정할 필요는 없습니다. 처음 접속할 때 ngrok 안내 화면이 나오면 **Visit Site**를 누릅니다.
화면 조작과 오류 대처는 [처음 이용하는 분을 위한 안내](./docs/user-guide.md)에 정리했습니다.

## 확인할 수 있는 내용

- 날짜별 검사수량과 불량기록
- 분석 대상 품목의 전류·전압·온도·처리시간
- 도금액 성분, 약품 사용량과 불량기록의 관계
- 월별 약품 사용량과 전력량
- 과거 자료로 계산한 예측과 실제 결과의 차이

검사자료에 품번과 생산묶음 번호(LOT)가 없어 날짜를 기준으로 비교합니다. 함께 변하는 경향이 있다고 해서 불량의 원인이 확인된 것은 아닙니다.

## 파일과 설치 안내

| 필요한 내용 | 안내 |
| --- | --- |
| 노트북 내용 확인 | [한국로텍_데이터분석.ipynb](./한국로텍_데이터분석.ipynb) |
| 내 Windows PC에 설치 | [Windows 설치 안내](./docs/windows-setup.md) |
| 서버에 Docker 설치·실행 | [Docker 운영 안내](./docs/docker-setup.md) |
| 서버에 Python으로 직접 설치 | [서버 설치 안내](./docs/server-setup.md) |

GitHub에서는 노트북 내용을 볼 수 있습니다. 실제 계산은 맨 위의 **분석 화면 열기** 링크에서 실행합니다.

회사 자료는 이 저장소에 포함하지 않습니다. 서버에는 담당자가 자료를 준비해 두었습니다. 내 PC에 직접 설치하는 경우에는 담당자에게 `raw`, `csv`, `prepared` 폴더와 `한국로텍_분석참고자료.json`을 별도로 받아야 합니다. 자세한 배치 방법은 Windows 설치 안내를 참고해 주세요.

Python 3.14 환경을 사용합니다. 2026-10-25에 실제 자료로 전체 실행과 검증 항목 15개를 확인했으며, 원본 파일은 변경되지 않았습니다.
