# 처음 이용하는 분을 위한 안내

이 분석 화면은 서버에서 실행됩니다. PC에 프로그램을 설치하거나 코드를 입력할 필요가 없습니다.

## 1. 분석 화면 열기

1. 담당자에게 받은 링크를 엽니다. [분석 화면 바로가기](https://wobbling-unreeling-moisten.ngrok-free.dev/lab/tree/%ED%95%9C%EA%B5%AD%EB%A1%9C%ED%85%8D_%EB%8D%B0%EC%9D%B4%ED%84%B0%EB%B6%84%EC%84%9D.ipynb)
2. ngrok 안내 화면이 나오면 **Visit Site**를 누릅니다.
3. 로그인 화면이 나오면 담당자에게 받은 로그인 코드를 입력하고 **Log in**을 누릅니다.

`한국로텍 데이터 분석`이라는 제목이 보이면 준비된 것입니다. 이미 계산된 결과가 화면에 표시됩니다.

## 2. 결과 보기

전체 내용을 한 번에 보려면 노트북 첫 부분의 **분석 보고서 열기**를 누릅니다.
항목별로 보려면 노트북을 아래로 내리면서 표와 그래프를 확인합니다.

| 표에 나오는 말 | 뜻 |
| --- | --- |
| 품번 | 제품을 구분하는 번호 |
| LOT | 같은 생산묶음을 구분하는 번호 |
| PPHV | 불량기록 건수 ÷ 검사수량 × 100. 한 제품에 여러 불량이 기록될 수 있어 불량 제품 비율과는 다를 수 있습니다. |
| 상관계수(r) | 두 값이 함께 변하는 정도. 양수는 함께 커지는 경향, 음수는 서로 반대로 변하는 경향입니다. |
| MAE | 예측과 실제 값의 평균 차이. 작을수록 예측이 잘 맞습니다. |
| %p | 비율의 차이를 나타내는 단위. 5%와 7%의 차이는 2%p입니다. |
| True / False | 계산 점검표에서 True는 통과, False는 확인이 필요하다는 뜻입니다. |

## 3. 분석 다시 실행하기

1. 화면 맨 위의 **Run(실행)** 메뉴를 누릅니다.
2. **Run All Cells(모든 셀 실행)**를 누릅니다.
3. 약 3~5분 기다립니다. 실행 중에는 칸 왼쪽에 `[*]`가 표시됩니다.
4. 맨 아래에 **분석 완료**가 나오면 계산이 끝난 것입니다.

화면의 한 칸을 **셀**이라고 부릅니다. 위 메뉴는 모든 칸을 위에서부터 차례로 실행합니다. 접힌 코드를 열거나 수정할 필요는 없습니다.
다시 실행하면 기존 `분석결과`가 갱신되므로 이전 결과가 필요하면 먼저 내려받습니다.

## 4. 결과 파일 내려받기

화면 왼쪽의 파일 목록에서 `분석결과` 폴더를 두 번 누릅니다.
원하는 파일을 마우스 오른쪽 버튼으로 누른 뒤 **Download**를 선택합니다.

| 파일·폴더 | 내용 |
| --- | --- |
| `한국로텍_분석보고서.html` | 전체 분석 보고서. 내려받은 파일을 두 번 누르면 브라우저에서 열립니다. |
| `tables` | 세부 계산표. CSV 파일은 Excel로 열 수 있습니다. |
| `figures` | 그래프 이미지 |

## 화면이 열리지 않거나 실행이 멈췄을 때

| 화면의 상황 | 할 일 |
| --- | --- |
| 로그인 코드를 모름 | 링크를 전달한 담당자에게 문의합니다. |
| 서버에 연결할 수 없다는 안내 | 담당자에게 서버와 접속 주소를 확인해 달라고 요청합니다. |
| `Kernel` 선택 창 | **Python 3 (ipykernel)**을 선택합니다. |
| 빨간 오류 메시지 | 해당 화면을 캡처해 담당자에게 전달합니다. |
| 보고서가 열리지 않음 | 왼쪽 `분석결과` 폴더에서 보고서를 내려받아 엽니다. 처음 실행하는 환경에서는 전체 실행을 먼저 마칩니다. |
| 왼쪽 파일 목록이 보이지 않음 | 화면 왼쪽 가장자리의 폴더 모양 아이콘을 누릅니다. |

설치 명령을 직접 입력할 필요는 없습니다. 내 PC에서 별도로 실행하려는 경우에만 [Windows 설치 안내](./windows-setup.md)를 따릅니다.
